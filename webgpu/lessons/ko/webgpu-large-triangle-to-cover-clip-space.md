Title: 클립 공간을 덮는 큰 삼각형
Description: 클립 공간을 덮는 큰 삼각형
TOC: 클립 공간을 덮는 삼각형

이 글에서는 작은 최적화 기법인 *트릭* 또는 *패턴*을 소개합니다.

화면, 캔버스 또는 텍스처 전체를 덮는 사각형을 그려야 할 때가 많습니다.
다시 말해 클립 공간 전체를 덮는 직사각형이 필요합니다.

가장 쉽게 떠올릴 수 있는 방법은 삼각형 두 개로 사각형을 만드는 것입니다.

<div class="webgpu_center">
  <div>
    <img style="width: 342px;" src="resources/quad-triangles.svg">
    <div>삼각형 두 개로 만든 클립 공간 사각형</div>
  </div>
</div>

```
    // 왼쪽 아래 삼각형
    -1, -1,
     1, -1,
    -1,  1,

    // 오른쪽 위 삼각형
    -1,  1,
     1, -1,
     1,  1,
```

정점 셰이더에 데이터를 전달하든 셰이더에 직접 값을 작성하든, 이런 작업은
흔히 필요합니다. 지금까지도 여러 번 사용했습니다. 예를 들어
[텍스처 가져오기에 관한 글에서 밉맵을 생성할 때](webgpu-importing-textures.html) 사용했습니다.

이 방법은 잘 동작하고 이해하기도 쉽습니다.

하지만 이 경우에는 더 간단한 방법이 있습니다. 클립 공간 전체를 덮을 만큼
큰 삼각형 하나를 대신 만들 수 있습니다. 다음 삼각형이 간단한 예입니다.

<div class="webgpu_center">
  <div>
    <img style="width: 512px;" src="resources/quad-triangle.svg">
    <div>분홍색 = 클립 공간</div>
  </div>
</div>

정점이 6개가 아니라 3개뿐입니다.

```
    -1,  3,
     3, -1,
    -1, -1,
```

GPU가 이 삼각형을 클립 공간에 맞게 잘라내므로 정점 6개로 만든 사각형과
같은 결과를 얻으면서 작성할 내용은 조금 줄어듭니다.

또한 GPU는 일반적으로 픽셀을 2x2 픽셀 단위로 그립니다. 여러 이유가 있지만
그중 하나는 효율성입니다. 따라서 삼각형 두 개를 그리면 두 삼각형이 만나는
가장자리에서 GPU가 추가 작업을 해야 합니다. GPU는 2x2 사각형을 처리하려고
하지만, 각 삼각형이 실제로 그려야 하는 픽셀 한두 개만 그리려면 추가 작업이
필요합니다.

삼각형 하나를 그리면 이 추가 작업을 피할 수 있습니다.

사실 이 추가 작업은 아주 작습니다. 전체 화면 사각형의 경우 60Hz 프레임의
0.5%도 사용하지 않을 것입니다. 무시할 수는 없지만 앱이 부드럽게 실행되는지
느리게 실행되는지를 결정할 정도는 아닐 가능성이 큽니다.

그렇지만 정점 3개를 입력하는 편이 6개를 입력하는 것보다 간단하므로,
성능 향상이 아주 작더라도 적절한 상황에서 사용하기 좋은 패턴입니다.
클립 공간 전체를 덮는 사각형이 필요할 때 사용할 수 있습니다. 예를 들어
밉맵 생성, 스카이박스 그리기, 후처리, 셰이더 토이 만들기 등이 있습니다.
